# Reviewing and improving Goals

Use [Goal progress, reviews and reporting](self_improvement_and_reporting.md)
for the current product model. AgentWorks reviews Goals as an ordinary Crew
agent through shared entry points and current access checks. Builder owns plan,
configuration and source changes. The platform stores metrics, decisions, run
records and costs; a review is evidence and advice, not a new permission level.

Use the shared measurement, assumption-audit, plan-design, plan-change-impact,
step-config, schedules, routing and artifact-review skills for the task at hand.
An improvement is proved by the actual affected path and source-backed readings;
a successful agent turn alone does not prove the business outcome improved.
