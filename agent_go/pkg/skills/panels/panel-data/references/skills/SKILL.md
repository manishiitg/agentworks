# Skills

Use skills action=list/skills action=search before skills action=install/skills action=import/skills action=uninstall. Inspect source/lock metadata; an inventory never proves who installed it. Remove only the requested package. Crew selection uses skills action=select; Goal selection uses settings action=update with the current version. For a new reusable procedure, create a focused skills/<name>/SKILL.md using scoped file tools, then list it to verify. Platform skills and user-installed skills are different inventories.

For skill sources, installation, memory versus procedures and focused skill authoring, Read [the detailed procedure](references/authoring.md).
