# Run a Goal

Read builder-reference/references/running-steps.md and execution-policy.md for the current Goal contract. Use runs action=step/runs action=debug for a saved step, runs action=start for the requested full Goal, runs action=step_status/runs action=active for results, and runs action=stop_step/runs action=stop_all for the selected active work. Discover route/group inputs before running. Runs perform real effects; do not simulate or run twice merely because the first response was slow. Verify actual status/output. Crew chat and Relay calls have separate execution contracts.
