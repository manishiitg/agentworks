# Chat history

Search this project’s saved conversation files by date/keyword with scoped file tools. Crew owner history is builder/conversation/; other callers’ history stays under their own crew-chats location. Goals use their saved Builder history, never another product’s chat folders. Use the current UI contract only if asked to open a conversation. Do not claim that a recalled summary is the complete transcript.

Goals and Relays have named Builder tabs. Use sessions (MCP: builder action=tabs with tab_action=list/open/read/rename/pin/order/close). Name a new agent before opening it. Pin controls whether it stays on the tab bar; order saves your named tabs in first-to-last order while your main Builder stays first. All project owners see named tabs; only each tab's person controls it. Run records are history: use Builder to chat. Agent messages are separate from human control. Use messages action=list_agents to see reachable projects and their authorized chat_id values, then messages action=send(target, chat_id, message). With Builder access, omit a Crew chat_id to message its main Builder; Run sharing keeps your own ask history; function calls keep their declared execution conversation. Planning, steps, schedules and AgentWorks stay on the server.
