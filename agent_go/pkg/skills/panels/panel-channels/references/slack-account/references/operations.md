## Personal Slack accounts

Use `integrations` to list saved accounts, connect a new one, add it to this item, remove it only here, or disconnect it everywhere. On the website, save or reconnect accounts in **Integrations → Slack account → Connect or manage accounts**. This item’s **Slack → Act in Slack** has **Use here / Remove here** for those same records; it does not start another sign-in. Existing Builders (including workflow editors) can explicitly add their own saved account; only the account owner signs in or reconnects, while owners or administrators can disconnect the saved connection. Signing in opens Slack in the browser, never a terminal or a request for a token in chat.

Connect once and explicitly add the account to every item that should use it. Shared runs use the account selected for this item, not the caller's Slack login. Messages appear as sent by that person with Slack's app attribution. Anyone who can run or change the item can send as that person through it. State this consequence when adding the account. Removing it here leaves other items connected. It stays selected until explicitly removed, including after its connector loses Builder access.

Discover the attached Slack connection with `mcp action=list`, inspect its live tools, then use `call_mcp_tool`. Resolve the actual recipient/channel before sending. For a new DM, Slack needs `im:write`; use the live conversation-creation tool rather than guessing a channel. Report a pending sign-in or Slack error accurately. Personal Slack and bot messaging use separate connections and identities. Use only tools actually available in this product; do not substitute a bot for the person's selected account, or the reverse.

An administrator sets up an internal Slack app named **AgentWorks** once in Sign-in apps. Enable its Slack MCP Server feature in the Slack app's Agents settings, register the returned callback URL and the required user scopes, then store its client ID and secret through the existing Vault tool in this Crew or Goal chat. Slack may require workspace app approval. See https://docs.slack.dev/ai/slack-mcp-server/.
