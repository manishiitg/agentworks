# WhatsApp

Use messages with channels_whatsapp_status to inspect your own linked phone,
channels_whatsapp_routing to inspect offered agent destinations, channels_whatsapp_unpair to
remove the pairing when requested, or channels_whatsapp_link for the pairing screen.
The same actions and website handlers apply in Crew chat and external MCP. A disconnect affects this person's one phone across their
projects, so explain that consequence when performing a requested disconnect.
Pairing needs the person's QR scan in WhatsApp → Linked devices. Then message
yourself, send @list, choose an offered Crew agent, and chat normally. Workflows are scripts; use their offered run actions when the work needs one.
The server decides which agents and workflow actions this person may use.
Use the existing picker; do not request a DM link code or invent a slug. A
generic linked-device category does not mean another person connected.
