# Secrets

Read the current value before changing it. The person’s Builder request authorizes the requested change under existing server checks. Discover the current tool schemas; use only tools offered in this chat. Opening a panel is optional and does not perform its action. Verify the saved result or execution receipt. If a capability is absent, name the concrete missing action rather than invent a website-only restriction. Provider sign-in and phone QR scanning still need the person.

Use list_secrets first. Store a value the person supplies with set_workflow_secret; delete only a requested stored value with delete_workflow_secret. Use update_project_global_secret_selection in Crew or settings in Goals to select/unselect shared names. Shared Vault operations require existing Vault authority. Never return, print or repeat secret values. Verify presence/selection by name only. Server secret tools make a successful write available to later shell calls; do not demand a new chat.
