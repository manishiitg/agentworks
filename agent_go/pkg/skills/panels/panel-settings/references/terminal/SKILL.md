# Terminal

Use terminal action=execute for server/project work within the admitted sandbox. Crew’s selected computer uses terminal action=local_execute only with its saved command access. The agent’s live terminal is a view of the running CLI; opening it does not start a second terminal session or grant access. Use ui action=capabilities/ui only for advertised views and acknowledged receipts. Verify command exit/output; a timed-out command may already have run.
