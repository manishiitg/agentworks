# MCP connections

In Crew and Goal chats these resources live together in the Vault panel.
Use panel-access for the panel inventory, project-use ticks and chat routing;
this procedure covers the underlying operation.

Start with mcp action=list and current selection. Use the admitted MCP discovery/install/add/edit/remove tools for a connection and mcp action=select (or action=deselect) in Crew or settings in Goals for project selection. Shared Vault access uses existing Vault tools and permissions. Reuse a saved connection; sign-in may still be a person action. Verify selection and tool availability, not just that a panel opened. Never hand-edit managed MCP configuration.

For Vault sign-in, discovery, selection and connection setup from chat, Read [the detailed procedure](references/connections.md).
