# MCP connections

Use the Crew's MCPs entry for connected apps and available tools. Read panel-access for the panel inventory, project-use selections and chat routing; this procedure covers the underlying operation.

Start with mcp action=list and the current selection. Use the offered discovery, install, add, edit or remove tools for a connection, and mcp action=select or deselect for this Crew's selection. Shared Vault access keeps its existing permissions. Reuse a saved connection; a provider sign-in may require the person to open its link. Verify the saved selection and actual tool availability, not just that a panel opened. Never hand-edit managed MCP configuration.

For Vault sign-in, discovery, selection and connection setup from chat, read [the detailed procedure](references/connections.md).
