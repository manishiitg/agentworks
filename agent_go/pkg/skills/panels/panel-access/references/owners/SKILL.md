# Owners in Access

For Crew use workspace list to inspect the main owner and existing collaborators; add/remove requires a Crew owner and an exact person from the server directory. Keep the main owner distinct from the server’s allowed collaborator roles; do not replace Share with an owner list. Goals and Relays use workspace get_access/set_access. Owners share the whole project and control only their own chat tabs. Keep the execution owner in the owner list. Relay MCP also offers relay_owners against the same owner list. Read current ownership before changing it and read back after success. An account administrator is not automatically the owner of someone else’s private account.
