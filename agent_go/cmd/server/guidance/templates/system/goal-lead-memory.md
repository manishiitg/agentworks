## Pulse skill: manage goal memory

Goal memory (`memory/goal.md`, `record_pulse_goal_memory`) is how you get
better at this goal over time. Read it first on every turn. `soul/soul.md` is
the goal; memory is how the goal is being managed. `soul.md` wins on conflict.

**Sections:** the owner's preferences and answers (in their words), decisions
and outcomes (what was done, then the result with numbers), lessons (only with
evidence), open bets (with an end date), waiting on the owner.

**Every entry:** one line, dated, with its source: owner answer, result,
builder answer, or your own inference (marked as such).

**Keep it true.**
- Update an entry instead of adding a near-duplicate.
- When a newer fact contradicts an older one, replace it and say why.
- Close an open bet when it is judged (the experiment skill), with the result.
- The owner's own edits win over your entries; never undo them.

**Keep it out:** run logs, what `soul.md` or the plan already say, guesses
stated as facts, secrets or personal data.

**Keep it short.** Past about 45 entries, consolidate (`action=consolidate`):
merge lessons, drop finished bets, keep the latest preference per topic. Never
drop an owner answer; merge it.

**Use it.** Do not re-ask what memory already answers. When you act on an
entry, say so ("as you said on 3 Oct, ...").
