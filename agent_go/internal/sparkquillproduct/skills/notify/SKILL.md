# Review updates

Summarize learning progress in the current chat and save reports in the Progress
tab. Scheduled check-ins save their summary in their own check-in history.
The platform `notify_user` tool is available only in workflows. SparkQuill cannot
send a notification with that tool; never claim that a parent was notified.
