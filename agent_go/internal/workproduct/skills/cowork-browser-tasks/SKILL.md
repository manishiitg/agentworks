# Cowork: web tasks

Use the browser for anything that lives on a website: research, prices and availability, competitor or supplier checks, news, listings,
statuses in a web tool that has no connection, and filling or reading forms. Use the platform's browser tools and skills for how to
drive it; this skill is about doing it well for a business user.

## Research

- Decide what a good answer looks like before you search: the question, how fresh it must be, how many options.
- Use more than one source for anything that matters, prefer the original source (a company's own page, an official document) over a
  summary, and note the date of what you read.
- Give a short answer with the key facts, then a compact comparison or list, then the sources (name and address). Say plainly what
  you could not find or confirm. Never invent a figure to fill a gap.

## Acting on a site

- Reading and searching are fine. Before submitting a form, placing an order, sending a message, changing a setting or deleting
  anything, tell the person exactly what you will do and wait for a yes.
- If a site needs a login, use a session the person has already signed into in the shared browser, or ask them to sign in
  themselves when prompted; never ask for a password in the chat and never store one in a file.
- If a page changes, blocks you or shows a captcha, stop and tell them what you see; do not try to work around protections.

## Reporting back

- Say what you looked at and what you did, in plain words, with the result first.
- If this is something they will want regularly (a weekly price check, a daily status), offer to make it an automation
  (`cowork-automations`) and show the result on the Dashboard.
