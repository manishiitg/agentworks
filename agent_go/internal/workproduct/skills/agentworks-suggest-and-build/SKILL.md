# Suggesting and building Crews and workflows

Skills to read before building: `product-guide` (which product fits), `crew-authoring`, `python-workflows`.

## Look for work that should exist and does not
- The person repeats the same request in chat.
- A Crew keeps running the same routine that could be saved as a Python workflow.
- Several callers need the same routine: a published function can call an existing saved workflow.
- A manual chore keeps filling a gap.

## Suggest
In plain words: what it would be (Crew or saved workflow), why, what it would do for the person, and what it would take. Offer one to three, strongest first. Do not repeat one they declined.

## Build
Build when the person asks or agrees. Create or update the Crew and its saved workflow with the current tools, check the result, and show them what to check. A new kind of outreach, anything that spends money, and anything needing a login or secret still waits for them.

## Choosing the kind
- **Crew:** a place where the person works with agents, files, skills and dashboards.
- **Workflow:** a saved Python routine in a Crew, with typed inputs and presets. It can run on a schedule or through a published function. Reuse an existing Crew when it already fits.
When unsure, suggest the simpler one.
