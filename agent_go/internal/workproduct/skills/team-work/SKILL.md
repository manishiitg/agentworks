# Team work

Use this skill to coordinate operations, product decisions, team priorities and chief-of-staff work. Read only the reference that matches the current request. Ask for missing source data or access in the current chat, then produce a useful result; there is no separate setup checklist. Use the project's existing tools, selections and sharing rules.

- [Chief of Staff](references/chief-of-staff.md): Turn authorized team goals, project status, and decisions into a sourced operator brief with accountable next actions.
- [Meeting Actions Coordinator](references/meeting-actions-coordinator.md): Extract owner-reviewed decisions and action items from authorized notes into a traceable register without silently assigning work.
- [Project Status Reporter](references/project-status-reporter.md): Reconcile project milestones, task state, and owner updates into a sourced status report with decisions and blockers.
- [Order Operations Coordinator](references/order-operations-coordinator.md): Investigate authorized order, fulfillment, carrier, and customer-service records into a prioritized owner action queue.
- [Vendor Researcher](references/vendor-researcher.md): Compare a bounded vendor set against owner-approved requirements, evidence, costs, and risks to prepare a reviewable shortlist.
- [Document Intake Assistant](references/document-intake-assistant.md): Extract customer-defined fields from authorized incoming documents, validate them against source pages and rules, and route uncertain values for review.
- [Product Feedback Coordinator](references/product-feedback-coordinator.md): Review a bounded customer feedback theme or released-feature adoption observation against current product evidence and owner criteria, then prepare a traceable decision.
- [Product Discovery Researcher](references/product-discovery-researcher.md): Turn authorized interviews, support cases and product observations into a bounded opportunity brief with uncertainty and a next research question.
- [Roadmap Prioritization Analyst](references/roadmap-prioritization-analyst.md): Compare candidate product opportunities against agreed goals, evidence, dependencies and capacity for a transparent owner decision.
- [Product Requirements Coordinator](references/product-requirements-coordinator.md): Turn an accepted product problem into a reviewable scope, behavior and acceptance contract for Design, Engineering and QA.
- [Product Release Coordinator](references/product-release-coordinator.md): Coordinate approved product scope, customer-facing claims, support readiness and adoption measurement for one exact release.
