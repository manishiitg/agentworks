# Landing Page Optimizer

This skill provides the Landing Page Optimizer capability (Landing-page conversion path analyst). Inspect one visitor journey and propose a bounded page revision or test grounded in evidence. When it is the Crew's primary role, lead with this method; when added to another Crew, apply the method under that Crew's existing identity. Work only within the owner's authorized website and data scope.

## First useful result

1. Confirm audience, traffic source, page intent, target action, and current measurement.
2. Inspect the full page and mobile path for clarity, proof, friction, accessibility, and loading issues.
3. Use authorized analytics or session data when present; distinguish observation from hypothesis.
4. Propose one bounded revision or experiment with a decision rule and required sample caveats.
5. Prepare a reviewable draft or test plan; compare results only after a valid measurement window.

Deliver **A page-level conversion diagnosis and reviewable improvement hypothesis.** Link the page observation, supporting behavior data, hypothesis, exact proposed change, metric, and decision rule.

## Test choice under low traffic

Inspect the exact page revision and mobile journey, target action, form and source/intent. Prioritize an observed broken action over a speculative copy test. State primary metric, guardrail, baseline and decision rule before a change. When traffic is too low for a credible split test, propose a reviewed single revision with a qualitative acceptance check and a later directional comparison, not a false winner.

## Fictional worked example

Input: ArborDesk /clinics rev4, 140 eligible visits/month, demo form works on desktop but mobile CTA falls below a large sticky banner in capture M-9. Good output: observed mobile friction, propose a reviewed banner-size fix on rev5, success=CTA visible and tappable on target devices, guardrail=no form regression, later monitor demo requests but do not call lift from 140 visits. Inadequate: “Run a 50/50 test for three days and declare the higher converting headline a winner.” The sample and rule cannot support that claim.

## Boundaries

Do not claim uplift without an experiment or comparable data; do not deploy a page or test without approval. Never claim a measurement unavailable in the source data. Do not select an external account, publish, send outreach, start paid spend, or activate a schedule, trigger, function, or Automation merely because this skill was added.
