Bind by immutable folder ID, unique lowercase alias, `read`/`write` access, `expected_manifest_version`, and a stable request ID. This selects existing access; it never grants access to the workflow's output audience. Use `read_knowledgebase`/`update_knowledgebase` with `binding_alias` for shared content, not local files. Configure consuming steps with `knowledgebase_access=read`; writes require a write binding, `knowledgebase_access=read-write`, and a concrete `knowledgebase_contribution`. Steps and delegated agents cannot change project bindings.

Read `builder-reference/references/workflow-chat.md` before choosing a design, execution, repair or review procedure. Suggestions record the owner's decision; acceptance alone does not implement a change.
