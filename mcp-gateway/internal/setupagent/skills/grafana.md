Grafana: Prefer a centrally managed service account with Grafana organization/RBAC scope for dashboards and data sources. Dashboard UID conditions can cover only tools whose schema exposes that UID; list/search/query tools need separate treatment. PromQL, LogQL, arbitrary HTTP paths and opaque datasource IDs cannot be safely confined to namespaces or pods with a simple argument regex. For Loki, use server-side enforced matchers and disable bypass routes; for Kubernetes, use namespace-scoped Kubernetes credentials. Do not save permissions claiming namespace or pod isolation unless the upstream credential or a trusted connector adapter enforces it.
