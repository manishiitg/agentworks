# Chat font assets

Self-hosted Latin WOFF2 subsets, normal weights 400 and 600, from Fontsource's npm packages:

- `@fontsource/fira-code` 5.3.0
- `@fontsource/ibm-plex-mono` 5.3.0
- `@fontsource/source-code-pro` 5.3.1

Each font's license is included here. JetBrains Mono already ships through the existing Fontsource dependency. No remote font requests are needed at runtime; other scripts fall back to system fonts.
